## 第 0 步：检查环境

打开 PowerShell（Windows 键 + R，输入 `powershell` 回车），逐条执行：

```powershell
python --version
git --version
```

**预期输出**：Python 3.10 以上、git 任意版本。

如果 `python` 命令不存在，去 [python.org](https://www.python.org/downloads/) 下载安装，
**安装时务必勾选 "Add Python to PATH"**（这一步忘了的话后面所有命令都会失败）。

> 💡 为什么需要 3.10+？项目里用到了 `X | None` 这种新式类型标注语法，3.9 会报语法错误。

确认一下这两行不是报错：

```powershell
python -c "import sys; print(sys.version)"
python -c "print(1 + 1)"
```

## 第 1 步：装依赖

```powershell
# 1. 进入项目目录（换成你自己的路径）
cd D:\视频蒸馏器

# 2. 创建虚拟环境
python -m venv .venv

# 3. 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 4. 安装依赖
pip install -r requirements.txt
```

**关于虚拟环境（venv）**：它是给每个项目独立的 Python 包目录，
避免这个项目装的包污染你电脑上其他项目。激活后命令行前面会出现 `(.venv)`。

如果第 3 步报错 `无法加载文件 ... 因为在此系统上禁止运行脚本`，执行一次：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

然后重新激活。

安装成功后验证：

```powershell
python -c "import fastapi, httpx, uvicorn; print('依赖 OK')"
```

**这个项目不需要 Node.js** —— 前端是原生 JS，第三方库已经放在 `web/vendor/` 里了。

## 第 2 步：配大模型（关键）

项目本身不包含 AI 能力，它调用**第三方大模型 API**。你需要一个 API Key。

### 选一个服务商

| 服务商 | 注册地址 | 大概价格 | 备注 |
| --- | --- | --- | --- |
| **DeepSeek** | platform.deepseek.com | 几块钱能用很久 | 推荐，中文好、便宜 |
| 阿里通义千问 | dashscope.aliyun.com | 有免费额度 | 国内直连稳定 |
| 月之暗面 Kimi | platform.moonshot.cn | 有免费额度 | 长文本强 |
| 硅基流动 | siliconflow.cn | 有免费模型 | 模型选择多 |
| 本地 Ollama | ollama.com | 完全免费 | 需要显卡，见下方说明 |

> ⚠️ **不要把自己的 API Key 提交到 GitHub**。项目已经用 `.gitignore` 排除了 `.env`，
> 但你自己要注意别手动 `git add` 它。

### 方式一：在网页里配（推荐）

启动服务后（第 3 步），点右上角 **⚙️ 设置**，填：

- **接口地址**：`https://api.deepseek.com/v1`
- **API Key**：`sk-你的key`
- **主模型**：`deepseek-chat`

点「测试大模型连接」，看到 ✅ 就说明通了。设置会存进 `data/settings.json`，改完立即生效不用重启。

### 方式二：用 .env 文件

```powershell
Copy-Item .env.example .env
notepad .env
```

填入：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-你的key
LLM_MODEL=deepseek-chat
```

保存关闭。环境变量的优先级高于网页设置。

### 各种服务商怎么填（照抄）

```ini
# DeepSeek
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# 阿里通义千问
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen-plus

# Kimi
LLM_BASE_URL=https://api.moonshot.cn/v1
LLM_MODEL=moonshot-v1-32k

# 硅基流动
LLM_BASE_URL=https://api.siliconflow.cn/v1
LLM_MODEL=deepseek-ai/DeepSeek-V3

# 本地 Ollama（API Key 可以留空）
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_MODEL=qwen2.5:14b
```

> 💡 项目只要求接口"兼容 OpenAI 格式"，所以任何提供了 `/v1/chat/completions`
> 的服务都能直接用。这也是为什么加新服务商不用改代码。

**省钱小技巧**：设置里的「导图模型」可以填一个更小更便宜的模型（比如 `qwen-turbo`），
因为生成思维导图只需要重排层级，不需要多聪明。

## 第 3 步：第一次启动

```powershell
python run.py
```

**预期输出**：

```
==============================================================
  B 站链接笔记生成工具
  网页地址：http://127.0.0.1:8848
  接口文档：http://127.0.0.1:8848/docs
  按 Ctrl+C 停止服务
==============================================================
INFO:     Uvicorn running on http://127.0.0.1:8848
```

浏览器会自动打开 http://127.0.0.1:8848 。

常用参数：

```powershell
python run.py --no-browser      # 不自动开浏览器
python run.py --port 9000       # 换端口（8848 被占用时）
python run.py --reload          # 改代码自动重启（开发时用）
```

**关于 `--reload`**：你在改后端代码时开着它，保存文件服务会自动重启，不用手动 Ctrl+C 再启动。
但注意它比较吃内存，日常使用不用开。

## 第 4 步：生成第一篇笔记

1. 找一个**短的、有字幕的**视频练手（建议 5-15 分钟，先别拿 3 小时的课试）
2. 复制链接，粘到输入框
3. 选风格：**详尽**（第一次先用这个，信息最全）
4. 点「生成笔记」

你会看到任务卡片上进度条依次走过：

```
解析链接 → 获取视频信息 → 获取字幕 → AI 整理笔记 → 生成导图 → 完成
```

**耗时参考**（30 分钟视频）：

- 有字幕：约 20-40 秒
- 无字幕需转写：约 1-3 分钟
- 1 小时以上长视频：3-5 分钟（因为字幕要分块处理）

第一次用建议开 `--reload` 模式并盯着服务端窗口的日志，能看清每一步在干嘛。

## 第 5 步：看懂产物

### 网页上

- **思维导图**页签：滚轮缩放、拖拽平移、点击节点折叠
- **Markdown**页签：完整笔记正文
- 右上按钮：`🖼 导出图片` / `SVG` / `🧠 XMind` / `⬇️ 下载 MD` / `🗑 删除`

### 磁盘上

每生成一篇笔记，会落 4 个文件到 `data/notes/`：

```powershell
dir data\notes
```

```
20250101-120000_视频标题.md            ← Markdown 笔记（主体产物）
20250101-120000_视频标题.mindmap.json  ← 导图数据结构（给程序用的）
20250101-120000_视频标题.xmind         ← 双击可以用 XMind 打开
20250101-120000_视频标题.opml          ← 通用大纲格式（幕布等软件可导入）
```

用记事本或 VS Code 打开 `.md` 文件，你会发现它不是纯文本 —— 里面到处是
`#`、`-`、`|`、`[...](...)`。这些是 Markdown 语法，
用 Typora、Obsidian、VS Code（装 Markdown Preview 插件）打开就能看到排版效果。

### 数据库里

`data/app.db` 是 SQLite 数据库，存任务和笔记的索引。
想直接看内容可以用 [DB Browser for SQLite](https://sqlitebrowser.org/) 打开，
或者用命令行：

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/app.db'); print(c.execute('SELECT title, word_count FROM notes').fetchall())"
```

## 第 6 步：让字幕能抓到（配 Cookie）

**这是最容易踩的坑，务必读。**

B 站的字幕接口（`x/player/wbi/v2`）**需要登录状态**。不配 Cookie 的话，
匿名请求只能拿到**空的字幕列表** —— 不是代码 bug，是 B 站的限制。

验证一下你的情况：

```powershell
python tools/selftest_network.py
```

如果看到 `字幕候选：0 条` 且 `未配置 Cookie`，就是这个问题。

### 解决办法：拿到浏览器 Cookie

1. 用 Chrome/Edge 打开并**登录** bilibili.com
2. 按 `F12` 打开开发者工具 → 切到 **Network（网络）** 标签
3. 按 `F5` 刷新页面
4. 在左侧请求列表里随便点一个（比如 `nav` 或 `web-interface`）
5. 右侧找到 **Request Headers（请求标头）** → 找到 `Cookie:` 那一行
6. **完整复制**那一长串值（形如 `SESSDATA=xxx; bili_jct=yyy; buvid3=zzz; ...`）
7. 粘贴到网页设置里的「B 站 Cookie」→ 保存

然后点设置面板里的「测试 B 站连通性」验证。

> ⚠️ Cookie 相当于你的登录凭证，**不要发给别人、不要提交到 GitHub**。
> 它存在本地 `data/settings.json` 里，这个文件已被 `.gitignore` 排除。
> Cookie 会过期（一般几个月），过期后重新复制一次即可。

**如果暂时不想折腾 Cookie**，可以直接跳到第 7 步开语音转写 —— 匿名也能下载到音频。

## 第 7 步（可选）：开启本地语音转写

没有字幕、也不想配 Cookie 时，可以让程序下载音频自己转写。

### 方案 A：本地免费（推荐，但第一次要下模型）

```powershell
pip install faster-whisper
```

然后在设置里把「语音转写」改成 **faster-whisper**，模型规格选 `small`。

- 模型大小：`tiny`(75MB) / `base`(140MB) / `small`(500MB) / `medium`(1.5GB) / `large-v3`(3GB)
- 第一次用会**自动下载模型**，需要等几分钟
- CPU 能跑但慢（1 小时视频可能要 10-30 分钟）；有 NVIDIA 显卡会快很多
- 完全离线、免费、不上传音频

### 方案 B：云端转写（快，但要花钱）

设置里把「语音转写」改成 **openai**，填转写接口和 Key（也可以复用大模型的地址）。
转写很快，但 1 小时音频大概几毛到几块钱。

> 💡 装没装 `ffmpeg` 会影响效果：装了会把音频转成 16kHz 单声道 wav（更小更准），
> 没装就直接把原始音频丢给转写后端。没有也不影响使用。

## 日常使用的 8 个技巧

### 1. 批量生成

输入框上方点 **「批量」**，一行一个链接：

```
https://www.bilibili.com/video/BV1xx411c7mD
https://www.bilibili.com/video/BV1GJ411x7h7?p=2
【带标题也行】https://www.bilibili.com/video/BV1yy411c7mE
```

会自动去重、跳过无效链接。最多 50 条。

**注意并发设置**：默认同时跑 2 个。开太高（比如 8）容易触发 B 站风控（412 错误）。
建议保持 2-3。

### 2. 重复生成不浪费

同一视频第二次生成会**命中缓存**，跳过下载和转写，直接从"AI 整理"开始，
速度快很多。任务卡片上会显示绿色的「缓存」徽标。

想强制重新抓字幕？勾选输入框旁边的「忽略缓存重抓」，或用任务卡片的「重生成」按钮。

### 3. 处理多分P视频

B 站的分P链接形如 `https://www.bilibili.com/video/BVxxx?p=3`。
把 `p=3` 那一段带上，程序就会处理第 3 P。
不带 `p=` 时默认处理第 1 P。

### 4. 时间戳跳转

笔记里每一节都有 `⏱ [15:00 - 35:00](链接)`。在支持 Markdown 链接的编辑器里
点一下就能跳回视频对应位置，复习时非常方便。

### 5. 三种风格怎么选

| 风格 | 什么时候用 |
| --- | --- |
| **精简** | 只是想快速了解一个视频讲了啥，或者视频是闲聊类 |
| **详尽** | 学习型视频、教程、讲座 —— **默认推荐** |
| **学术** | 论文解读、理论讲解，会强调概念定义和方法论 |

### 6. 在 Obsidian / Typora 里管理笔记

`data/notes/` 就是一个普通的文件夹。你可以把它设成 Obsidian 的 vault，
笔记会自动出现在库里，还能用 `[[双链]]` 和标签管理（笔记里的 `#关键词` 正好能当标签用）。

### 7. 导出到手机看

```powershell
# 下载 MD（网页按钮也行）
curl.exe -OJ "http://127.0.0.1:8848/api/notes/笔记ID/download?kind=md"
```

或者直接把 `.md` 文件复制到手机用 Markdown 阅读器打开。

### 8. 找不到东西时看日志

服务端窗口会打印每一步的日志，比如：

```
23:36:08 | INFO | platform.bilibili | 字幕候选 2 条：['中文（中国）', 'English']
23:36:09 | INFO | cache | 命中转写缓存：bilibili / BV1GJ411x7h7 P1（711 字，来源 subtitle_ai）
23:36:15 | INFO | llm.client | 调用模型 deepseek-chat…
```

出现问题时先看这里，比在网页上瞎点有用得多。

## 验证安装是否成功

项目自带三套自检脚本，建议装完后跑一遍：

```powershell
# ① 离线自检：不需要网络和 API Key，89 项检查
python tools/selftest_offline.py
# 预期结尾：通过 89 项，失败 0 项

# ② 前端一致性检查
python tools/check_frontend.py
# 预期结尾：通过 12 项，失败 0 项

# ③ 联网自检：真实请求 B 站
python tools/selftest_network.py
# 预期：能拿到视频标题；字幕 0 条属正常（未配 Cookie）
```

如果第 ① 项有失败，说明环境有问题（依赖没装好/Python 版本太低）。

还有两个可选的自检：

```powershell
# 端到端：起一个"假的大模型"，不需要真 API Key 就能跑完整流程
python tools/selftest_e2e.py

# 对着正在运行的服务打接口（需要先用 python run.py 起服务）
python tools/smoke_http.py
```
