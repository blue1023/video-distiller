# 📖 学习文档

这套文档是**专门给初学者写的**（假设你之前没怎么做过完整项目）。
按顺序读，或者按你的需要挑着读。

## 五分钟了解这个项目

**它做什么**：粘贴一条 B 站视频链接 → 自动抓字幕 → 调大模型理解内容 →
生成一份带时间戳跳转的 Markdown 笔记 + 一张可以导出 XMind 的思维导图。

**技术栈**：Python + FastAPI + SQLite（后端）／原生 JavaScript（前端）／
任意 OpenAI 兼容的大模型 API。

**代码规模**：`src/` 约 3800 行 Python，`web/` 约 1700 行前端代码。

**一句话架构**：`路由收请求 → 丢后台异步任务 → 流水线依次调用【平台层拿字幕】【LLM 层做结构化】【模板层渲染 Markdown】→ 落盘 + SSE 推送进度`

## 关键概念速查表

| 概念 | 在这个项目里指什么 | 在哪看 |
| --- | --- | --- |
| **流水线（Pipeline）** | 从链接到笔记的 11 个步骤 | `src/pipeline.py :: run_pipeline()` |
| **平台适配器** | 一套统一接口，屏蔽 B站/本地文件/未来其他平台的差异 | `src/platforms/base.py` |
| **两阶段生成** | 模型只输出 JSON，Markdown 由 Python 模板渲染 | `src/llm/notes.py` |
| **map-reduce** | 字幕超长时先分块摘要，再合并成最终结果 | `_structure_transcript()` |
| **转写缓存** | 同一视频第二次生成时跳过下载和转写 | `src/core/cache.py` |
| **SSE** | 服务器单向推流，用于实时推送任务进度 | `src/webapi/routes_tasks.py :: events()` |
| **并发闸门** | 用 `asyncio.Semaphore` 限制同时运行的任务数 | `configure_concurrency()` |
| **数据库迁移** | 老版本数据库自动补上新列，不用删库重建 | `src/core/db.py :: _migrate()` |

## 这个项目值得学的地方（面试可聊）

1. **面向接口编程** —— `BasePlatform` 让加新平台不用改核心代码
2. **异步任务 + 实时进度** —— 后台执行、SSE 推送、断线降级轮询
3. **Prompt 工程的可靠性设计** —— 强制 JSON 输出 + 解析失败自动重试修复
4. **长文本处理** —— map-reduce 分块摘要
5. **缓存失效策略** —— 指纹里带上所有会影响结果的变量
6. **向后兼容** —— 数据库迁移 + 回归测试保护老用户
7. **工程习惯** —— 三套自检脚本（离线/联网/端到端）、CI、防御性错误处理
